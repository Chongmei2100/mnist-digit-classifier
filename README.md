## 项目做什么
输入是手写数字图片，输出是 0-9 的数字，主要工作是使用 PyTorch 提供的基础层，组合并训练一个小型神经网络，完成手写数字识别任务。
为什么选择这个入门项目:
- 简单，容易上手
- 有现成的数据集
- 有现成的工具


## 怎样运行
需要先训练生成参数，再执行评估和预测。也可以在项目根目录依次执行：
```
python train.py
python evaluate_saved.py
python evaluate_test.py
python predict.py examples/digit_4.png
```

## 环境安装:
本项目在 Windows11、Python 3.13.9、CPU 环境下运行验证:
1. 安装 Python，进入项目目录。
2. 创建并激活虚拟环境。
3. 安装依赖：`python -m pip install -r requirements.txt`
4. 首次训练会下载 MNIST，需要网络连接。

**注意：**
- 首次训练前需要创建 checkpoints 文件夹。
- 参数文件由 `python train.py` 生成，不随源码提交。
- 表中的准确率是本次保存模型的实测结果；重新训练可能有小幅差异。
- examples/digit_4.png 是预测演示所需的样例文件，之后要随源码提交。


## 本次实验结果
记录了训练和测试评估过程中的网络结构、训练轮数、学习率，以及模型在验证集和官方测试集上的准确率：
- 网络结构：输入层 784 个神经元（MNIST 图片是 28×28=784 像素，展平后就是 784 维），隐藏层 128 个神经元，输出层 10 个神经元（对应数字 0~9 共 10 类）；
- 隐藏层采用激活函数ReLU，优化器采用SGD，学习率为0.01、训练轮次为 3 轮，50,000 张训练集，10,000 张验证集；

| 数据 | 数量 |  准确率 |
|--|--|--|
| 验证集 | 10,000  |  90.54%  |
|官方测试集 | 10,000 |91.45% |

## 局限与错例
### 局限
目前只适合黑底、浅色笔画、居中的单个数字；

### 错例说明：
通过运行`python inspect_errors.py`命令，可以查看已保存模型在验证集上的前三张错例，以下为可能的原因：
- 第一张预测出错的图片是一个倾斜的5，可能和3的下半身很像，导致模型预测出错，但是人眼还是很容易识别出来就是5的；
- 第二个图片是一个比较瘦长的2，体型上比较像一个有点弯曲的1；
- 第三张出错的图片是一个下半身实心且很瘦的8，识别成了9，这张图片人眼也很难识别。
